# 特定商取引法に基づく表記

> **内部メモ（公開ページには出ない）**
> この文面は案です。公開前に松田さんの確認と、専門家（行政書士・弁護士など）の確認を受けてください。
>
> - 【 】の部分は松田さんが決めて埋める
> - 個人事業主は、住所と電話番号を「請求があれば遅滞なく開示します」と書くこともできる（Stripe の案内。docs/stripe-prelaunch.md C-1）。ただしコンビニ払いを使う場合は、住所と、固定電話か 050 番号を載せる必要がある（A-3）
> - 次の値は管理画面の設定と同じにする: キャンセルの締切（レッスンの前日20時）、毎月1日の引き落とし、余った回数は翌月末まで、退会・休会は翌月1日から
> - 支払い方法は、今はカードと現金だけ（PY-04）。コンビニ払い・PayPay は今は使わない。使うときに【コンビニ払い・PayPay を使う場合】の部分を戻す
> - 入会金は今のところなし。入会金を設けたら「販売価格」「お支払いの時期」「返品・返金」に書き足す
> - **未確定**: 未払いが続いた場合の扱い（何日で予約を取り消すか）。決まるまで具体的な日数は書かない
> - ページの上部か下部の、すべてのページから見える場所にリンクする（PayPay の審査の条件。A-4）

| メールアドレス | 【メールアドレス】 |
| 販売するもの | 音楽レッスン（ポピュラーピアノ・ドラムのマンツーマンレッスン）の月謝制の受講。ポピュラーピアノは対面またはオンライン、ドラムは対面のみ |
| 販売価格 | 月謝（1回1時間）: 月1回 6,000円、月2回 11,000円、月3回 15,000円、月4回 20,000円。月5回以上は1回ごとに5,000円を足した額【税込か確認】。入会金はいただきません。体験レッスン: 【体験レッスンの料金・時間】 |
| 商品代金以外の必要料金 | 【教材費などの追加費用。なければ「なし」】。お支払いの手数料は教室が負担します。インターネットの通信料（オンラインレッスンを含む）はお客さまのご負担です |
| お支払い方法 | クレジットカード（Apple Pay・Google Pay を含む）、現金（教室でお支払い）【コンビニ払い・PayPay を使う場合: 、PayPay、コンビニ払い】 |
| お支払いの時期 | 入会時: 入会手続きの画面で、最初の月の月謝をお支払いいただきます。翌月から: 毎月1日に、その月の月謝をお支払いいただきます。クレジットカードは毎月1日に自動で引き落とします。現金の場合は教室でお支払いください。体験レッスンの料金は、当日教室で現金でお支払いください |
| サービスを受けられる時期 | お支払いを確認したあと、予約の画面からレッスンを予約できます。レッスンは予約した日時に行います。オンラインレッスンの参加用のURLは、講師からご連絡します |
| 契約の期間 | 退会のお申し出があるまで、毎月自動で続きます |
| 退会・休会 | 退会・休会は教室にご連絡ください。お申し出の翌月1日から、お支払いとレッスンが止まります。お支払い済みの月は月末までレッスンを予約でき、返金はありません |
| キャンセル | レッスンの前日20時までのキャンセルは、使った回数をお戻しします。それより後のキャンセルと無断欠席は、回数を使ったものとして扱います。教室や講師の都合で休みになったレッスンは、回数をお戻しします |
| 回数の有効期限 | その月の回数は、翌月末まで使えます。翌月に持ち越した回数を、さらに次の月に持ち越すことはできません |
| 未払いの場合 | お支払いを確認できない場合、レッスンの予約ができなくなることがあります。詳しい扱いは別途お知らせします |
| 返品・返金 | サービスの性質上、お支払い済みの月謝の返金はいたしません。ただし、教室の都合でレッスンを行えない場合はこの限りではありません |
| 動作環境 | 予約などの画面は、iPhone の Safari、Android の Chrome、パソコンの主なブラウザの最新版でご利用いただけます |
