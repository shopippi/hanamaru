> - 【 】の部分は松田さんが決めて埋める
> - 個人事業主は、住所と電話番号を「請求があれば遅滞なく開示します」と書くこともできる（Stripe の案内。docs/stripe-prelaunch.md C-1）。ただしコンビニ払いを使う場合は、住所と、固定電話か 050 番号を載せる必要がある（A-3）
> - 次の値は管理画面の設定と同じにする: キャンセルの締切（24時間前）、毎月1日の引き落とし、未払いの猶予（7日）、退会・休会は翌月1日から
> - ページの上部か下部の、すべてのページから見える場所にリンクする（PayPay の審査の条件。A-4）

| --- | --- |
| 事業者の名称 | 【事業者の名称（個人事業主の場合は氏名）】 |
| 運営責任者 | 【運営責任者の氏名】 |
| 所在地 | 【住所（郵便番号から）】（個人事業主の場合の書き方: 請求があれば遅滞なく開示します） |
| 電話番号 | 【電話番号】（受付時間: 【受付時間】）（個人事業主の場合の書き方: 請求があれば遅滞なく開示します） |
| メールアドレス | 【メールアドレス】 |
| 販売するもの | 音楽レッスン（個人レッスン・グループレッスン）の月謝制の受講 |
| 販売価格 | 入会金: 【入会金（税込）】／月謝: 【コース名・月の回数・月謝（税込）】。料金はすべて税込で表示します |
| 商品代金以外の必要料金 | 【教材費などの追加費用。なければ「なし」】。お支払いの手数料は教室が負担します。インターネットの通信料はお客さまのご負担です |
| お支払い方法 | クレジットカード（Apple Pay・Google Pay を含む）、PayPay、現金（教室でお支払い）【コンビニ払いを使う場合: コンビニ払い】 |
| お支払いの時期 | 入会時: 入会手続きの画面で、入会金と最初の月のレッスン代をお支払いいただきます。翌月から: 毎月1日に、その月の月謝をお支払いいただきます。クレジットカードは毎月1日に自動で引き落とします。PayPay【コンビニ払いを使う場合: ・コンビニ払い】は、毎月1日にお送りするお支払いの画面からお支払いください |
| サービスを受けられる時期 | お支払いを確認したあと、予約の画面からレッスンを予約できます。レッスンは予約した日時に行います |
| 契約の期間 | 退会のお申し出があるまで、毎月自動で続きます |
| 退会・休会 | 退会・休会は教室にご連絡ください。お申し出の翌月1日から、お支払いとレッスンが止まります。お支払い済みの月は月末までレッスンを予約でき、返金はありません |
| キャンセル | レッスンの24時間前までのキャンセルは、使った回数をお戻しします。それより後のキャンセルと無断欠席は、回数を使ったものとして扱います。教室や講師の都合で休みになったレッスンは、回数をお戻しします |
| 未払いの場合 | 毎月1日から7日たってもお支払いを確認できない場合、その月のご予約は取り消しとなり、お支払いを確認できるまで予約できません |
| 返品・返金 | サービスの性質上、お支払い済みの月謝・入会金の返金はいたしません。ただし、教室の都合でレッスンを行えない場合はこの限りではありません |
| 動作環境 | 予約などの画面は、iPhone の Safari、Android の Chrome、パソコンの主なブラウザの最新版でご利用いただけます |
