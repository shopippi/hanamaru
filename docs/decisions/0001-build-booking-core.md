# 0001 予約の中核を自前で作る（LibreBookingを使わない）

- 日付: 2026年10月20日
- 状態: 決定（作成者）
- 関係: 要件定義書 2章の2・3、6.1、7.1／[フェーズ0の検証報告](../phase0-report.md)

## 背景

フェーズ0で LibreBooking 3.5.1 を検証したところ、標準・設定だけで要件を満たせたのは11項目中2項目だった。月ごとの回数、講師による空き時間の更新、保護者と子ども、承認待ちは拡張サービスで作る必要があり、ユーザー作成・グループ権限の API に不具合もあった。

## 決定

予約の中核（空き時間、予約、締切、回数、権限）も TypeScript の拡張サービスで作り、LibreBooking は使わない。管理者の画面も新しく作る。

要件定義書の次の箇所は、この決定に合わせて作成者が更新する（v1.8 想定）。

- 2章の2「LibreBookingを土台にし、本体は改造しない」→ 予約の中核も自前のサービスで作る
- 2章の3、4章「管理者の画面は LibreBooking の標準画面」→ 管理者の画面も新規
- 6.1「予約の中核: LibreBooking＋MariaDB」→ 自前のAPI＋PostgreSQL
- 7.1 の「要検証」→ すべて自前で実装

## 技術構成

| 要素 | 採用 | 理由 |
| --- | --- | --- |
| 言語 | TypeScript（Node.js 22） | 要件の指定。生徒・講師・管理の画面とAPIで型を共有できる |
| API | Hono | 小さく、標準の Request/Response で書ける。将来 LINE の画面から同じ API を呼べる（2章の4） |
| DB | PostgreSQL ＋ Drizzle ORM | 予約の重複防止にトランザクションと行ロックが必要。SQL に近い書き方で、マイグレーションを SQL で残せる |
| テスト | Vitest ＋ PGlite | PGlite はメモリ上で動く PostgreSQL。Docker なしで本物の SQL を使った受入テストを流せる |
| 入力検証 | Zod | 設定値（3.8）と API の入力を同じ仕組みで検証する |
| 決済 | Stripe 公式 SDK | 要件の指定（2章の7） |
| メール送信 | Resend（HTTP API を直接呼ぶ。SDK は足さない） | 作成者が承認（2026年11月1日「好きな技術を使っていい」）。無料枠（月3,000通）で足り、独自ドメインで送れる。比較は `docs/mail-options.md` |
| 画面 | React ＋ Vite | ホーム画面アプリ（4.5）の Service Worker と manifest は自前で書き、プラグインは足さない |

パスワードのハッシュ（scrypt）、二段階認証のワンタイムパスワード（TOTP）は Node.js 標準の `crypto` で実装し、ライブラリを足さない。

## 結果

- ルールは `apps/api/src/domain/` にだけ置く（2章の6）。画面は API を呼ぶだけにする
- 回数は `credit_ledger` に増減をすべて記録し、月ごとの合計を残り回数とする（OP-04）
- サーバーは API と PostgreSQL だけになり、PHP と MariaDB を持たない

## あとから足した開発用の道具（2026年11月1日）

作成者の承認（2026年11月1日「好きな技術を使っていい」）を受けて、品質の確認のために次の道具を足した。どれも開発と CI でだけ使い、本番のイメージには入らない。

| 道具 | 使い方 | 理由 |
| --- | --- | --- |
| Playwright の WebKit（iPhone 13 の設定） | CI の `e2e-webkit` で、生徒・講師の通しテスト、画面の決まり、スマホ幅の見た目を流す。手元では `E2E_WEBKIT=1 pnpm e2e` | iPhone の Safari と同じ描画エンジンで、Chrome では出ない違いを早く見つける（MB-08 の実機確認の代わりではない） |
| `@axe-core/playwright` 4.10.2 | `e2e/tests/a11y.spec.ts`。WCAG 2.1 AA の重い違反があれば失敗 | 色のコントラスト・名前のないボタンなどを毎回自動で調べる（UI-05・UI-19） |
| Lighthouse 12.6.1 | `npx` でその都度使う。依存には入れない | 読み込みの速さ・見た目のずれ（CLS）を測る |
